# MDAC Worker

当前目录提供一个 **dry-run Worker**，用于验证手机端创建任务之后的队列协作、字段映射、客户资料快照、逐项结果、幂等领取和失败隔离。它不会打开真实网页、不会连接 Gmail、不会调用 OCR，也不会提交任何真实 MDAC 注册。

## 本地运行

在项目根目录执行：

```bash
python3 worker/dry_run_worker.py --output worker/demo_results.json
```

脚本会生成一个包含一项成功和一项资料校验失败的演示批次。输出中的护照号码已脱敏，结果明确标记 `submitted: false` 和 `result_confirmed: false`，不能被当作真实注册成功。

## 与旧版脚本的映射

`map_mdac_fields()` 保留了 `mdac-auto-v2` 的关键网页选择器与值转换：日期输出为 `DD/MM/YYYY`，性别使用 `男 → 1`、`女 → 2`，区域代码默认 `60`，并暂时将 `#pob` 映射到国籍。客户领域模型仍保留独立的 `place_of_birth`，未来确认网页字段含义后只需替换适配器映射。

## 接入真实系统前必须替换的部分

第一，使用 Supabase 服务端安全凭证实现原子领取 `QUEUED` 批次、逐项锁定、心跳和超时恢复。第二，将 `DryRunWorker` 的字段校验接到经过授权的网页自动化适配器，并保留“已提交但结果未知”的中间状态。第三，为 Gmail IMAP 单独实现消息 ID 去重、护照号码优先匹配和有限重试；邮箱应用专用密码只放在办公室电脑的受保护本地配置。第四，真实运行前需要确认 MDAC 网页自动化授权、服务条款、资料保护、截图保留期限和账号登录方式。
